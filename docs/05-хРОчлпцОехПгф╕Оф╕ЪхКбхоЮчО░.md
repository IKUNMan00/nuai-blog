# 《我的知识小栈》后端接口与业务实现

| 项目 | 内容 |
| --- | --- |
| 框架 | Flask 3.1 + Flask-SQLAlchemy 3.1 |
| 认证 | Flask-Login（Session） |
| 表单安全 | Flask-WTF CSRFProtect |
| 接口风格 | 服务端渲染表单为主 + 少量 JSON API |
| 入口 | `run.py`（开发）/ `wsgi.py`（生产） |
| 应用工厂 | `app/__init__.py::create_app()` |

---

## 1. 请求处理总览

```text
HTTP 请求
  → Flask 路由匹配
  → before_request（后台角色 / API 登录）
  → CSRF 校验（POST）
  → 视图函数：参数校验 → ORM 查询/写入 → 事务提交
  → 模板渲染 / JSON 响应 / 重定向
  → after_request：安全响应头
  → 全局错误处理（400/403/404/413/500）
```

### 1.1 认证与权限装饰器

| 装饰器 / 机制 | 作用 | 失败行为 |
| --- | --- | --- |
| `@login_required` | 要求登录 | 302 到登录页，带 `next` |
| `admin_bp.before_request` | 要求 `admin` | 未登录 → 登录页；读者 → 403 |
| `@account_bp.before_request` | 账号中心登录 | 302 登录页 |
| `@api_bp.before_request` | API 登录 | 302（表单场景）/ 403（角色不足） |
| `current_user.is_admin` | 模板显示控制 | 仅显示层，不能替代服务端校验 |

### 1.2 CSRF

- 所有 HTML 表单包含：

```html
<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
```

- JS 请求从 `<meta name="csrf-token">` 读取，放在 `X-CSRFToken` 头；
- 测试环境通过 `WTF_CSRF_ENABLED=False` 关闭；
- 过期/缺失 token：HTML 返回 400 页面，API 返回 JSON `{ok:false}`。

## 3. 接口详细说明

### 3.1 登录 `POST /auth/login`

**请求**（`application/x-www-form-urlencoded`）：

```text
csrf_token=...
identifier=admin          # 用户名或邮箱
password=Admin@123
remember=on               # 可选
next=/admin/posts         # 可选，仅站内
```

**成功**：302 到 `next` 或后台/首页，Flash “欢迎回来”。

**失败**：

| 情况 | 状态码 | 页面 |
| --- | --- | --- |
| 缺少字段 | 400 | 登录页 + 提示 |
| 账号/密码错误 | 400 | 登录页 + 统一提示 |
| 账号停用 | 403 | 登录页 + 提示 |

**安全**：

```python
user = db.session.scalar(
    db.select(User).where(or_(User.username == identifier, User.email == identifier.lower()))
)
if not user or not user.check_password(password):
    flash("用户名/邮箱或密码不正确，请重新输入。", "danger")
```

不区分“用户不存在”和“密码错误”，避免账号枚举。

### 3.2 注册 `POST /auth/register`

**请求**：

```text
username=alice
email=alice@example.com
display_name=小满
password=Password123
confirm_password=Password123
```

**校验**：

| 字段 | 规则 |
| --- | --- |
| username | `^[A-Za-z0-9_]{3,20}$`，唯一 |
| email | 邮箱格式，唯一，转小写 |
| display_name | 2–20 字符 |
| password | ≥8 位，含字母和数字 |
| confirm | 与 password 一致 |

**成功**：创建 `role='reader'`，自动登录，302 首页。

**注意**：公开注册不授予后台权限；博主账号由 `flask create-admin` 或 `seed-demo` 创建。

### 3.3 文章列表 `GET /posts`

**查询参数**：

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `q` | string | 关键词，最多 80 字符，匹配标题/摘要/正文 |
| `category` | int | 分类 ID |
| `tag` | int | 标签 ID |
| `page` | int | 页码，默认 1 |

**示例**：

```http
GET /posts?q=Flask&category=1&page=2
```

**服务端逻辑**：

```python
stmt = _published_posts()
if q:
    pattern = f"%{q}%"
    stmt = stmt.where(or_(
        Post.title.ilike(pattern),
        Post.summary.ilike(pattern),
        Post.content_md.ilike(pattern),
    ))
if category_id:
    stmt = stmt.where(Post.category_id == category_id)
if tag_id:
    stmt = stmt.join(Post.tags).where(Tag.id == tag_id)
stmt = stmt.order_by(Post.is_top.desc(), Post.published_at.desc())
pagination = db.paginate(stmt, page=page, per_page=6, error_out=False)
```

**渲染**：`main/posts.html`，包含 `pagination`、`categories`、`tags`、当前筛选。

### 3.4 文章详情 `GET /posts/<id>`

**行为**：

1. 查询已发布文章；不存在时，博主可预览草稿，访客 404；
2. 同一会话同一篇只计一次浏览；博主预览不计；
3. 查询已通过评论（分页 20 条/页，`cpage`）；
4. 查询收藏数、当前用户是否收藏；
5. 查询同分类相关文章最多 3 篇；
6. 查询上一篇/下一篇。

**浏览计数**：

```python
if post.status == "published" and not current_user.is_admin:
    viewed = session.get("viewed_posts", [])
    if post.id not in viewed:
        post.view_count = (post.view_count or 0) + 1
        db.session.add(PostView(post_id=post.id, visitor_key=visitor_key()))
        session["viewed_posts"] = (viewed + [post.id])[-30:]
        db.session.commit()
```

### 3.5 提交评论 `POST /posts/<id>/comments`

**请求**：

```text
csrf_token=...
guest_name=林间          # 未登录必填
guest_email=lin@example.com  # 可选
content=请问蓝图之间共享工具函数放在哪里？
website=                 # 蜜罐，正常用户留空
```

**校验**：

- 内容 2–800 字符；
- 游客昵称 2–20 字符，邮箱可选但格式正确；
- 蜜罐非空视为机器人，直接返回“已提交”；
- 同会话 20 秒内重复提交被拒绝；
- 登录用户忽略游客字段，记录 `user_id`。

**结果**：写入 `comments`，`status='pending'`，`ip_hash`，302 回详情 `#comments`。

### 3.6 收藏 `POST /posts/<id>/favorite`

- 需登录；
- 已收藏则删除，否则插入；
- 联合主键防重复；
- 成功后 302 回 `next`（站内校验）或文章详情；
- 详情页按钮显示收藏数。

### 3.7 Markdown 预览 `POST /api/markdown/preview`

**请求**：

```json
{ "content": "## 标题\n\n**加粗**" }
```

**响应 200**：

```json
{
  "ok": true,
  "html": "<h2>标题</h2>\n<p><strong>加粗</strong></p>",
  "characters": 16
}
```

**失败**：

| 情况 | 状态码 | 响应 |
| --- | --- | --- |
| 未登录 | 302 | 登录页（浏览器 fetch 会得到 HTML，前端显示“预览暂不可用”） |
| 非博主 | 403 | `{"ok": false, "message": "只有博主账号可以使用编辑器。"}` |
| body 不是 JSON | 400 | `{"ok": false, "message": "内容格式不正确。"}` |
| 内容 > 200000 | 413 | `{"ok": false, "message": "内容过长，无法预览。"}` |

**安全**：服务端 `render_markdown` 完成 Markdown → HTML → bleach 白名单过滤，前端只负责 `innerHTML`。

### 3.8 图片上传 `POST /api/upload`

**请求**：`multipart/form-data`，字段 `file`。

**成功 200**：

```json
{
  "ok": true,
  "url": "/static/uploads/2026/10/6f1c....png",
  "markdown": "![cover.png](/static/uploads/2026/10/6f1c....png)",
  "name": "cover.png",
  "size": 84213
}
```

**失败 400**：

```json
{ "ok": false, "message": "仅支持 JPG、PNG、GIF、WEBP 格式的图片。" }
```

**校验链路**：

1. 文件存在且非空；
2. ≤5MB；
3. Pillow `verify()` + 重新打开；
4. 格式在 `JPEG/PNG/GIF/WEBP`；
5. 宽高 ≥16；
6. UUID 重命名，按年月目录保存；
7. 写 `attachments` 记录。

### 3.9 后台文章保存

**表单字段**：

| 字段 | 说明 |
| --- | --- |
| `title` | 2–150 字符 |
| `summary` | ≤300，空则自动摘要 |
| `content_md` | 10–200000 字符 |
| `category_id` | 可空，必须存在 |
| `tags` | 多个标签 ID |
| `new_tags` | 逗号分隔，最多 5 个，每个 ≤20 字符 |
| `cover_image` | URL 或 `/static/` 路径 |
| `cover_file` | 可选，本地上传 |
| `is_top` | `on` 表示置顶 |
| `action` | `publish` / `draft` |

**保存逻辑**：

```python
post.content_html = render_markdown(data["content_md"])
post.status = "published" if action == "publish" else "draft"
if post.status == "published" and not post.published_at:
    post.published_at = datetime.now()
if post.status == "draft":
    post.published_at = None
_sync_tags(post, data)
db.session.commit()
```

### 3.10 评论审核

`POST /admin/comments/<id>/approve|reject|delete`

| action | 行为 |
| --- | --- |
| `approve` | `status='approved'`，记录 `audited_at` / `audited_by` |
| `reject` | `status='rejected'`，记录审核信息 |
| `delete` | 物理删除 |
| 其他 | 400 |

审核后重定向回 `next`（站内）或当前状态列表。

### 3.11 删除分类

```python
db.session.execute(
    update(Post).where(Post.category_id == category.id).values(category_id=None)
)
db.session.delete(category)
db.session.commit()
```

保证文章不随分类删除，只归入未分类。

### 3.12 删除附件

```python
delete_uploaded_file(attachment.file_path)  # 校验路径在 uploads 内
db.session.delete(attachment)
db.session.commit()
```

## 4. 数据访问示例

### 4.1 首页数据聚合

```python
category_rows = db.session.execute(
    select(Category, func.count(Post.id))
    .outerjoin(Post, and_(Post.category_id == Category.id, Post.status == "published"))
    .group_by(Category.id)
    .order_by(Category.sort_order)
).all()
```

### 4.2 分页与预加载

```python
stmt = (
    select(Post)
    .where(Post.status == "published")
    .options(
        joinedload(Post.category),
        joinedload(Post.author),
        selectinload(Post.tags),
    )
    .order_by(Post.is_top.desc(), Post.published_at.desc())
)
pagination = db.paginate(stmt, page=page, per_page=6, error_out=False)
```

### 4.3 近 7 日浏览趋势

```python
recent_view_times = db.session.scalars(
    select(PostView.viewed_at).where(PostView.viewed_at >= week_start)
).all()
day_counter = Counter(
    value.strftime("%Y-%m-%d") for value in recent_view_times if value
)
```

不在 SQL 中用 `DATE()`，避免 MySQL/SQLite 差异；数据量在课程范围内可接受。

### 4.4 标签同步

```python
def _sync_tags(post, data):
    tags = list(db.session.scalars(select(Tag).where(Tag.id.in_(data["tag_ids"]))).all())
    for name in data["new_tags"]:
        tag = db.session.scalar(select(Tag).where(func.lower(Tag.name) == name.lower()))
        if not tag:
            tag = Tag(name=name, color=...)
            db.session.add(tag)
        tags.append(tag)
    post.tags = tags
```

先校验 ID 是否存在，避免伪造表单写入不存在的关联。

## 5. 错误码与响应约定

### 5.1 HTML 页面

| 状态码 | 触发 | 页面 |
| --- | --- | --- |
| 200 | 正常 | 对应模板 |
| 302 | 登录成功、创建成功、筛选重定向 | 目标页 |
| 400 | 表单校验失败、CSRF 过期 | 原页面 + Flash / 400 |
| 403 | 读者访问后台、停用账号登录 | 403 |
| 404 | 文章不存在、草稿被访客访问 | 404 |
| 413 | 上传超过 8MB | 413 |
| 500 | 未捕获异常 | 500，事务回滚 |

### 5.2 JSON API

```json
{ "ok": true, "...": "..." }
```

```json
{ "ok": false, "message": "用户可读的错误说明" }
```

- 成功 `200`；
- 参数错误 `400`；
- 无权限 `403`；
- 内容过大 `413`；
- 未登录 API 目前由 `login_required` 返回 302；前端 fetch 会进入失败分支并提示刷新登录。若要做纯 API，可改为返回 401 JSON。

## 6. 关键业务规则

| 规则 | 实现位置 | 说明 |
| --- | --- | --- |
| 公开注册只能是读者 | `auth.register` | 角色硬编码 `reader` |
| 草稿前台不可见 | `main.post_detail` | 非博主 404 |
| 评论默认待审核 | `main.comment_create` | `status='pending'` |
| 前台只显示已通过 | `main.post_detail` | `WHERE status='approved'` |
| 收藏联合唯一 | `favorites` 主键 | 重复收藏不会写入两条 |
| 分类删除文章置空 | `admin.category_delete` | 不删除文章 |
| 标签删除只解除关联 | `admin.tag_delete` | 不删除文章 |
| 文章删除级联清理 | ORM cascade + FK | 评论/收藏/浏览记录 |
| 浏览量会话去重 | `session.viewed_posts` | 最近 30 篇 |
| 管理员预览不计数 | `main.post_detail` | `current_user.is_admin` 跳过 |
| 上传文件 UUID | `utils.persist_image` | 防覆盖/穿越 |
| 删除文件路径校验 | `utils.delete_uploaded_file` | 必须位于 uploads |
| 外链跳转校验 | `is_safe_url` | 防开放重定向 |

## 8. 扩展接口建议

如果后续要把前端改成 SPA 或提供开放 API，建议：

1. 新增 `/api/v1` 版本前缀；
2. 使用 Token / JWT 替代 Session；
3. 统一响应结构 `{code, message, data}`；
4. 未登录返回 401 JSON，而不是 302；
5. 为写接口增加限流与幂等键；
6. 使用 OpenAPI/Swagger 生成文档。

当前课程项目以服务端渲染为主，接口数量克制，便于讲解与维护。
