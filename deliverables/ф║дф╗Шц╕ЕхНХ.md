## 2. 运行与演示

### 2.1 Docker（推荐，需安装 Docker Desktop）

```bash
docker compose up -d --build
# 前台 http://127.0.0.1:5000
# 后台 http://127.0.0.1:5000/admin
```

### 2.2 本机运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# 修改 DATABASE_URL 与 SECRET_KEY
flask init-db
flask seed-demo
flask run
```

### 2.3 演示账号

| 角色 | 用户名 | 密码 |
